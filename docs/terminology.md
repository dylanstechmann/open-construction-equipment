# Terminology

| Term | OCE meaning |
|---|---|
| OCE | Open Construction Equipment, the multi-license learning project. |
| OCE-CTL-01 | First concept reference: battery-electric compact track loader; not a released machine model. |
| Target | Desired unvalidated behavior/value, including every number in the current concept. |
| Assumption | Provisional input subject to analysis; not a fact. |
| TBD | A required decision/value is absent. Never replace it with an inferred fabrication or service setting. |
| Rated operating capacity (ROC) | Target capacity only; definition, attachment/load center, stability and structural basis require applicable earth-moving standards and engineering. |
| ROPS / FOPS | Roll-over / falling-object protective structure concepts requiring controlled design and applicable evaluation. The CAD operator-zone frame makes neither claim. |
| Quick attach / universal-style | Conceptual coupler interface; universal or OEM compatibility has not been established. |
| Independent safety chain | Actuator power/torque-inhibit concept with manual reset, independent of ordinary/autonomy computing. No safe-state design or integrity rating is established. |
| Safe state | Machine response determined per hazard and operating state; it may not be power removal in every actuator path. Torque-off might imply freewheeling; hydraulic de-energization alone might imply load drop; both require analysis of brakes, drift, load holding, residual motion, and operator/site constraints. |
| Manual control | Direct operator control through the validated vehicle-control path under permissives and independent protective chain. Does not mean risk-free or autonomous-ready. |
| Autonomy-ready | Reserved mechanical/electrical/data interfaces for later research. No sensing coverage, localization, navigation, or autonomous safety capability is claimed. |
| Simulation-only | Current autonomy boundary. Simulation may guide engineering but is not physical validation and never authorizes energization or field trials. |
| Command freshness | Validity age and sequencing of sensed/command data; concrete timeout remains TBD pending control analysis. |
| LOTO | Lockout/tagout under an approved site procedure with individual control of energy sources and verified zero-energy state. Tagging alone is not isolation. |
| Stored energy | Residual electrical charge, hydraulic/pneumatic pressure, suspended/gravitational loads, spring force, thermal energy, or track/drive potential after shutdown. |
| Qualified person | Person with demonstrable competence and authorization for the specific electrical, hydraulic, welding, engineering, test, or service task—not a generic project contributor. |
| Calibrated instrument | Identified measurement device with traceable calibration appropriate for the measured range and within its due date. |
| Safety case | Structured, evidence-supported argument for acceptable risk in an explicit context; currently open and pre-release. |
| WPS / PQR | Welding Procedure Specification / Procedure Qualification Record (terminology varies by jurisdiction/code); project gate requires applicable qualified documents and welder qualification. |
| Weld map | Drawing-linked identification of welds, applicable WPS, inspection/NDT and acceptance/records for a unit. |
| NCR | Nonconformance report documenting objective mismatch, containment, and authorized disposition; not silently repaired. |
| Proposed interval | Learning-project planning placeholder not sourced from an OEM or regulation. Final released design and law determine service frequency. |
| Released | Signed responsible-owner authorization for one exact configuration and limited activity; not commercial production or universal safety approval. |
| Agent-run analysis | AI/agent-generated calculation or document marked as unreviewed assistance, not personal owner work or approval. |
