# Architecture decision records

ADRs record significant choices and their unresolved consequences. Status `Proposed` is a design direction, not engineering approval. New ADRs use zero-padded sequential IDs and link affected hazards, requirements, interfaces, and verification gates. Do not erase rejected alternatives; append a superseding ADR when evidence changes the decision.
