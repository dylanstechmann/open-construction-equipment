# PR-005: Undercarriage and track service

## Scope and competence

Qualified undercarriage/mechanical technicians only. Required released track/final-drive/tensioning OEM procedure, load/support fixture design, approved machine recovery/lifting arrangement, soil/debris/fluids controls, isolated energy mapping and calibrated tools/measurement methods. No track tension, wear limit, fastener torque, gear lubricant or removal sequence is released.

An elevated/removed track/roller, compressed/tensioned track, released adjuster, spring or suspended machine has stored energy. Never place body parts in a track bight, cut a track, strike a tensioner, release grease/pressure indiscriminately, or work beneath a machine supported only by a jack/tracks/hydraulics.

## Controlled service flow

1. Identify exact track handedness/module, drive/brake/tension configuration, fault/impact and recent undercarriage history. Review debris packing and interaction with skid-steer loads.
2. Secure work area and perform PR-002 before confined access. Position on released stable ground and support the chassis/module using engineered rated points/supports; independently verify stability before uninstalling retention.
3. Remove debris only if it can be done without stored-motion access. Release tension using the exact OEM tooling/procedure only after support and exclusion. Record initial condition rather than destroying evidence prematurely.
4. Inspect track links/belt and guides, sprocket/final drive, rollers/idlers, tensioner, frame mounting, seals/lubricant leakage, corrosion, abnormal wear and fastener/retainer condition. Use released wear methods and actual readings; no visual “life percent.”
5. Replace/service only released compatible components by controlled sequence; preserve left/right identity and torque-to-component traceability. For sealed/non-serviceable items use supplier disposition, not improvised opening.
6. Refit and set released alignment/tension with approved support and calibrated measurement, then verify guards, retention, brakes and final-drive/lubricant closure. Any structural damage is an engineering NCR, not weld/repair in the field.
7. Before travel, complete static inspection and separately authorized gradual functional/brake/asymmetric-drive checks by qualified staff with no bystanders or debris-ejection exposure.

## Return gate

PR-008 plus qualified reviewer verifies actual wear/tension/clearance where required, support/release sequence, parts/fasteners/lots, calibrated torque and test results, spills and NCR closure. Keep replaced tracks tension-controlled until released storage/transport/disposal. No travel or autonomous test is authorized merely by completing reassembly.
